# GoreeCloud YouTube Player — Branding

## Authority

Canonical product artwork is owned by `GoreeCloud/goreecloud-branding-assets`. This repository is a consumer of approved identity assets, not the authority that invents product artwork.

## Current verified state

No approved product-specific GoreeCloud YouTube Player artwork was found in the current canonical branding repository during the September 14, 2026 repository review.

Therefore:

- no placeholder, text badge, emoji, generic video glyph, YouTube logo, or locally improvised icon may be represented as the official GoreeCloud YouTube Player identity;
- any Development placeholder must remain clearly non-canonical and must not be promoted into release/store/public-brand surfaces;
- provider marks must not be repurposed as GoreeCloud product identity;
- approved product artwork must originate from the canonical branding repository and then be synchronized into this repository with provenance.

## UI identity

The application must use the current approved Glaze UI design system for GoreeCloud-controlled graphical surfaces. The current published consumer target is Glaze UI 1.3.0, but this repository has not established application conformance.

Glaze UI provides presentation identity; it does not substitute for product-specific icon/logo approval.

## Acceptance gate

Product-specific artwork, launcher/store artwork, release graphics, and related branding remain a production-readiness gate. This document records the absence honestly rather than approving a substitute.
